What are Vector & Embedding Weaknesses?

RAG systems retrieve documents from a vector store and feed them to the model as context. If that store can be poisoned, or retrieval can be steered, an attacker controls what the model "knows".

Retrieved context is data, not instructions — but vulnerable systems treat it as trusted.

Attack Strategy
  • Inject a document containing your target keywords
  • Make it more similar to your query than the real doc
  • Or query the confidential doc directly at LOW
Mitigation
  • Authenticate & authorize document sources
  • Per-tenant index isolation
  • Sanitise & validate ingested content
  • Treat retrieved context as untrusted
